# 📘 ITAI2376 Capstone Project: AI Research Assistant Agent

**Student:** Alicia Gonzalez G  
**Tool:** Google Colab (Python)  
**Description:**  
This AI agent takes a research topic, searches the web using DuckDuckGo, visits the top articles, extracts text, and auto-summarizes each one using Hugging Face's Transformers model (`distilbart-cnn-12-6`). This helps users quickly understand key info on any topic.

**Technologies Used:**  
- DuckDuckGo Search API (`duckduckgo_search`)  
- HuggingFace Transformers (`pipeline("summarization")`)  
- Web scraping (`requests`, `BeautifulSoup`)  
- Google Colab (no paid API keys)

**Use Case:**  
A personal research assistant for students, writers, and anyone needing quick summaries of recent info online.
